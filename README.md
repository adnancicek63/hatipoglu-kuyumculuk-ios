# Hatipoğlu Kuyumcu Takip - iOS & Web Sistemi

Profesyonel iOS tabanlı kuyumcu stok, canlı altın kurları, müşteri emanet ve cari hesap takip sistemi.

## 🚀 Codemagic.io ile iOS IPA Derleme
1. Bu depoyu [Codemagic.io](https://codemagic.io)'ya bağlayın.
2. Depo içindeki `codemagic.yaml` otomatik olarak algılanır.
3. **Start new build** butonuna tıklayarak Mac Mini M2 bulut makinelerinde **HatipogluGold.ipa** dosyanızı oluşturun.
4. Derleme tamamlandığında **Artifacts (Eserler)** bölümünden `.ipa` dosyasını iPhone cihazınıza doğrudan yükleyin.

## 💻 Yerel Geliştirme (Local Development)
```bash
npm install
npm run dev
```
